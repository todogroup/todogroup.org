## TODO OSPO アンバサダープログラムへの参加 {#joining-the-todo-ospo-ambassadors-program}

TODO アンバサダーは、TODO Group コミュニティの公認の担い手として OSPO のエコシステムを支えます。

### アンバサダーの活動

経験や関心に応じて、さまざまな形で貢献できます。すべてに取り組む必要はありません。

アンバサダーには、次のことが期待されます。

- TODO の取り組み、資料、コミュニティ活動に関連する貢献を毎月少なくとも 1 件行う
- TODO Group の資料を活用・紹介し、OSPO のベストプラクティスを広める
- 資料、リポジトリ、調査、ガイド、ワーキンググループの成果物に貢献する
- 実践者や新しい参加者を支援し、メンタリングや参加の手助けをする
- ワーキンググループ、OSPOlogy イベント、ミートアップなどを主導・支援する
- 実践者やコミュニティからの意見を TODO に届ける
- TODO のミッションに沿い、専門性と包摂性を持って TODO を代表する

貢献には、次のような例があります。

- OSPO Book、TODO ガイド、用語集、マインドマップ、成熟度モデル、ツール集、調査、ホワイトペーパーの執筆やレビュー
- TODO のブログやニュースレターへの執筆、外部ブログでの TODO の紹介
- リポジトリへの PR、Issue、レビュー、翻訳、事例、その他の改善
- ワーキンググループの共同チェアや進行役として成果物づくりを支えること
- 地域での OSPOlogy イベントや TODO ミートアップの開催・支援
- TODO の資料を紹介・活用する教材、講演、チュートリアル、動画の制作
- 質問への回答、メンタリング、新しい参加者への支援

TODO の資料、取り組み、コミュニティ活動につながらない一般的な OSPO やオープンソースの発信は、通常、アンバサダーとしての貢献には含まれません。詳細は[アンバサダーマニュアル](https://github.com/todogroup/governance/blob/main/structure/ambassadors/ambassador-manual.md)をご覧ください。

### 責任

アンバサダーは、地域のミートアップ、OSPOlogy、OSPO に関する発信やメンタリングを通じてコミュニティの参加を支えます。協力関係を築き、新しい参加者を迎え、プログラムへの意見を届け、OSPO のベストプラクティスと TODO の活動を世界に広めます。

### 参加要件

- 18 歳以上であること
- [TODO 行動規範](/ja/code-of-conduct/)に従うこと
- [Linux Foundation の独占禁止方針](https://www.linuxfoundation.org/legal/antitrust-policy)に従うこと

### 評価基準

申請者は、次のうち少なくとも 1 つを満たす必要があります。

- Awesome OSPO、OSPO Landscape、ウェブサイト、ブログ、資料、調査、ワーキンググループの成果物など、TODO の活動に継続的に貢献している
- TODO 一般メンバー組織の代表として、組織のユースケースや実践的な情報を TODO の資料や活動に提供している
- OSPOlogy のプログラム委員、主催者、ラウンドテーブルのメンターまたは登壇者である
- TODO ワーキンググループで活動する共同チェアまたは進行役であり、関連分野での進行、メンタリング、コンテンツ制作の経験が 1 年以上ある

申請には、TODO コミュニティへの参加や貢献を確認できるリンクなどの根拠を添えてください。

### 特典

- アンバサダーページへの公式プロフィール掲載
- Linux Foundation が発行する TODO OSPO Ambassador の Credly バッジ
- TODO と OSPO コミュニティへの貢献の認知
- 世界のアンバサダーとのネットワーク
- イベントや地域ミートアップに対する TODO Group と Linux Foundation のプラットフォーム支援
- Linux Foundation エコシステムの関連する機会への検討
- TODO 名義の調査、研究、ホワイトペーパー、イベント、コミュニティ活動に専門知識を提供する機会
- コミュニティの発信を通じて貢献が紹介される機会
- 一部の Linux Foundation イベントの割引コード
- 提供可能な場合の限定グッズ

TODO OSPO アンバサダーは有給の役職ではありません。

### よくある質問

#### 申請の流れは？

[マニュアル](https://github.com/todogroup/governance/blob/main/structure/ambassadors/ambassador-manual.md)で現在の要件を確認し、条件を満たす場合は[申請フォーム](https://github.com/todogroup/governance/issues/new/choose)から参加と貢献の根拠を添えて申請してください。TODO 運営委員会が審査します。

#### いつ申請できますか？

要件を満たしていれば、年間を通じていつでも申請できます。

#### ミートアップの開催は必須ですか？

いいえ。イベントの開催は重要な貢献の 1 つですが、資料やリポジトリ、ワーキンググループ、調査、ブログ、教材、メンタリング、コミュニティ支援などでも貢献できます。

#### どのような活動が貢献になりますか？

実際の TODO の活動や資料につながり、その理解、利用、改善、貢献に役立つ活動です。マージされた PR、ワーキンググループの成果物や進行、OSPOlogy の開催、TODO 資料の使い方を教える発信、確認できるコミュニティ支援などが含まれます。詳細はマニュアルをご覧ください。

#### 貢献はどう記録しますか？

[貢献報告フォーム](https://github.com/todogroup/governance/issues/new?template=ambassador-submission.yaml)から、確認できるリンクなどの根拠と、関連する TODO の資料、活動、ワーキンググループを添えて報告します。TODO が活動を認知し、コミュニティ全体での貢献を理解するために役立ちます。

#### 報酬はありますか？

有給の役職ではありません。貢献の認知、一部イベントの割引、グッズ、コミュニティでの機会などの特典があります。

#### 所属組織が変わるとどうなりますか？

称号は勤務先ではなく個人に与えられるため、転職で自動的に資格が変わることはありません。引き続き参加と貢献の要件を満たす必要があります。

#### 任期はどのくらいですか？

任期は 2 年です。任期中も参加状況を確認し、貢献の継続性と質、TODO との関連、コミュニティへの影響、専門的な姿勢、連絡への対応、継続する意思などを考慮します。長期間の活動停止や連絡への応答がない場合は、任期の途中でも見直すことがあります。任期終了時には、その時点の要件に沿って更新を申請できます。

#### 質問はどこに送れますか？

非公開のアンバサダー向け Slack チャンネル、または <steering-committee@todogroup.org> にご連絡ください。
